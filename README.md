# Team Productivity App

A role-based task assignment and time tracking web application.

## Features
- Task assignment
- Time tracking with breaks
- Excel export
- FastAPI backend
- React frontend

## Tech Stack
- Backend: FastAPI, SQLAlchemy
- Frontend: React (Vite)
- Database: SQLite (MVP)
